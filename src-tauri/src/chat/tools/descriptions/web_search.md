公开互联网搜索。用于查找当前新闻、政策入口、法院/政府/企业官网页面、公开公告、行业资料入口,或在本地知识库和元典专业数据库无法覆盖时寻找网页线索。

使用顺序:
1. 专业法律数据默认不要先用本工具。法条、司法解释、裁判案例、企业涉诉/被执行/经营风险等,应先用本地知识库和元典工具。
2. 用户明确说「联网」「搜网页」「查官网」「查新闻」「找公开资料」时,可以直接使用本工具。
3. 如果本地知识库和元典都没有命中,或者问题明显涉及最新动态、政策公告、官网页面、软件下载/产品说明等元典不覆盖的信息,可以把本工具作为兜底。
4. 如果用户意图不清,或者检索词可能暴露案件隐私,先调用 ask_user,让用户选择「只用本地/元典」「去联网补充公开资料」「我来提供链接」。

隐私纪律:
- query 里不要放案件隐私、当事人身份证号/手机号、完整案情、内部文件路径、API key、客户商业秘密、未公开证据内容。
- 必须抽象成公开可检索的关键词,例如把「张三诉李四买卖合同纠纷欠款 386 万」改成「买卖合同 逾期付款 违约金 裁判规则」或限定到官方站点。
- 不能搜索登录后台、私有云盘、带 token 的分享链接。

结果使用:
- 搜索结果只是线索,不等于已核实事实。需要正文时继续调用 web_fetch 读取具体 URL。
- 法律结论、条号、案号不能只靠搜索结果定稿;应回到元典、官方页面或用户材料核验。
- 回答中引用网页线索时,说明网页标题和 URL;正式引用应在 <CITATIONS> 中使用 type=web。
