# 类案检索

1. 把争点拆成可检索的法律关系、关键事实、程序阶段和裁判要素。
2. 使用可用案例检索工具；优先指导性案例、人民法院案例库、最高法院及同辖区高相关案例。
3. 不以关键词相同代替事实相似，逐案比较关键事实、争议焦点、裁判理由和结果。
4. 明确案例层级、时间、地域和是否仍具有参考价值。
5. 输出“支持我方、对我方不利、可区分”三类，并给出实际引用建议；不得编造案号。
