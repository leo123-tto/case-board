# 刑事案件深度分析

1. 以无罪推定和证据裁判为基础，严格区分指控事实、证据内容与分析判断。
2. 按犯罪构成要件检查指控闭环，并同步审查主观明知、因果关系、共同犯罪等关键问题。
3. 分析证据的合法性、真实性、关联性及相互印证，识别非法证据和合理怀疑。
4. 检查侦查、审查起诉、审判各阶段程序问题，提出可执行的申请或异议。
5. 同时准备无罪、罪轻、程序性和量刑辩护的分层方案，不虚构事实或案例。
