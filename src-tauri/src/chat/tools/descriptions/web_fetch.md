读取一个公开网页 URL,抽取标题和正文文本。适合读取用户给的公开网页链接、web_search 返回的结果、法院/政府/企业官网公告、公开政策页面、公开产品说明、新闻报道等。

使用边界:
1. 只支持公开 http(s) URL。localhost、内网地址、file://、link-local、保留地址会被拒绝,避免模型误读本机服务或内网系统。
2. 不要读取含案件隐私的云盘、登录后台、私有系统、临时签名下载地址或带 token 的链接。用户给了这类链接时,先用 ask_user 提醒隐私风险,让用户改为上传文件或提供公开页面。
3. 本工具只读网页,不提交表单、不登录、不下载大文件、不绕过访问限制。
4. 返回正文可能被截断。若正文很长,先依据标题、摘要和可见正文判断;需要精确段落时请用户给更具体 URL 或页面片段。

专业数据纪律:
- 网页内容是公开线索,优先级低于本案材料、本地知识库和元典专业数据库。
- 涉及法条、案例、裁判规则时,读取网页后仍应尽量用 search_laws/get_law_article/search_cases/get_case_detail 等专业工具核验。
- 官网公告、政策通知、机构介绍等元典不覆盖的信息,可以直接作为网页来源,但要保留 URL。

引用方式:
- 引用网页内容时,在 <CITATIONS> 中使用 type=web,source 写网页标题或站点名,url 写网页地址,quote 写短摘录。
- 不要把网页里的未经核验事实写成确定法律结论;必要时标注「公开网页显示」「需人工核验」。
