# Agent 集群定义

## 架构总览

```text
                        ┌─ opposing-counsel-agent ─┐（红队扫描，独立视角）
                        │                          │
Gate 1 提取 → Gate 2 核验 → Gate 3 推理 → Gate 4 交付
    ↑            ↑             ↑             ↑
extraction-  verification-  reasoning-   delivery-
  agent        agent          agent        agent
                              │
                          dispatcher
                        （多争议焦点并行调度）

会话启动 → docket-watcher（期限扫描，≤7天紧急预警）
```

## 7 个法律专用子 Agent 定义

### 1. extraction-agent（Gate 1·提取）

- **职责**：全量案卷结构化提取
- **纪律**：只搬不分析。禁止出现「可疑」「可能」「涉嫌」「显然」「有问题」「应该」「建议」等主观判断词
- **产出**：结构化事实表 + 材料索引 + 材料掌握程度声明
- **硬约束**：每条事实可追溯到文件+页码，原文摘录≥20字
- **版本**：v1.0.0

### 2. verification-agent（Gate 2·核验）

- **职责**：矛盾识别 + 交叉核验 + 可信度分级
- **三层矛盾**：对方内部矛盾 / 对方说法与证据矛盾 / 双方证据矛盾
- **产出**：矛盾清单 + 疑点清单 + 事实可信度分级 + 外部主体核验表
- **特殊能力**：引用案例全文风险扫描（三层：效力核验/不利认定扫描/风险评级）+ 检索覆盖率自检 + 法规标准有效性核验 + 主体信用自动查询

### 3. reasoning-agent（Gate 3·推理）

- **职责**：P-F-C 三段论链 + 四视角对立审查 + S×L 风险评级
- **核心能力**：要件事实拆解 / 类案五维度相似度评估 / 期限不可逆性检测 / 不确定性升级
- **产出**：推理四表（事实/法律适用/要件事实/策略）+ P-F-C 链
- **按案件类型加载**：`[civil]` 加载 `rules/51_civil_domain.md`；`[criminal]` 加载 `rules/52_criminal_domain.md`

### 4. opposing-counsel-agent（Gate 3·红队扫描）

- **职责**：对方律师视角的红队扫描，独立于主会话分析倾向
- **7 维度系统攻击**：事实攻击 / 证据攻击 / 法律解释攻击 / 程序攻击 / 因果链攻击 / 金额攻击 / 策略攻击
- **每个弱点标注**：攻击成功率（高/中/低）× 攻击影响（致命/严重/中度/轻度）+ 防御方案 A（预防性）/B（应对性）/C（替代性）
- **可并行**：与 Gate 4 交付阶段并行执行

### 5. dispatcher（Gate 3·并行调度器）

- **职责**：多争议焦点案件的子任务拆分与并行推理调度
- **能力**：自动检测独立争议焦点 → 生成子 reasoning-agent → 汇总合并
- **适用**：≥3 个争议焦点或跨法律领域的复杂案件

### 6. delivery-agent（Gate 4·交付）

- **职责**：文书组装 + 门禁自检 + 一致性校验
- **五道门禁**：stance_gate → evidence_gate → authority_gate → script_gate → style_gate
- **补充门禁**：通用 G1-G6 + 领域补充 Y1-Y5（民商事）/ Z1-Z6（刑事）
- **三维校验**：VIE 输入校验 + 生成后校验 + 校验报告生成

### 7. docket-watcher（会话启动·期限监控）

- **职责**：案件期限自动跟踪与预警
- **触发**：每次会话启动自动扫描全部在办案件
- **预警规则**：≤7 天红色 / ≤30 天橙色 / 已过期灰色
- **覆盖期限**：上诉期（判决15日/裁定10日）/ 举证期限 / 财产保全续封 / 申请鉴定期间 / 管辖权异议期 / 申请执行期限

## 信息传递规范

- 阶段间传递：前一阶段的完整产物 + 未完成事项清单
- 置信度标注：每条结论标注「高置信/中置信/低置信/待核验」
- 来源锚点：所有事实附带来源（文件+页码）
- 待办追踪：`memory/unresolved.md` 实时更新

## 依赖与并行规则

```
依赖链：extraction → verification → reasoning → delivery
并行机会：
  - opposing-counsel-agent 在 reasoning 完工后可立即启动，与 delivery 并行
  - 多争议焦点案件：各焦点可并行 spawn 独立 reasoning-agent
  - 下游阻塞规则：上游 after 钩子未通过 → 下游全部阻塞
```
