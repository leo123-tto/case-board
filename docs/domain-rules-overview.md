# B 类领域规则体系 · 民商事 / 刑事

## 设计原则

领域规则按**案件类型文件级隔离**，不同类型互不加载对方规则。通用规则（A类）同时适用，冲突时以领域规则为准。

## 一、民商事（civil）· `rules/51_civil_domain.md`

### 法律依据
- 《民法典》（2021年1月1日施行）为首要依据
- 《公司法》（2024年7月1日施行）为公司纠纷首要依据

### 四大案件类型

#### 合同纠纷
- **成立与效力**：要约/承诺/形式/可撤销（重大误解/欺诈/胁迫/显失公平）/无效（违反强制性规定/违背公序良俗/恶意串通）/格式条款规制（不合理免责/加重对方/限制权利→无效）
- **履行与违约**：三大履行抗辩（同时履行/先履行/不安抗辩）+ 违约行为认定 + 损害计算（《民法典》第584条：实际损失+可得利益）+ 违约金调整（第585条）+ 定金罚则（第587条）
- **合同解除**：约定解除 + 法定解除（不可抗力/预期违约/迟延经催告仍不履行/根本违约）+ 解除权行使期限（1年）+ 解除后责任
- **五种有名合同**：买卖（风险转移/瑕疵担保/所有权保留）/借款（禁止高利贷/自然人实践性）/租赁（≤20年/买卖不破租赁/优先购买权）/承揽（定作人任意解除权）/建设工程（无效情形/工程款优先权）

#### 侵权纠纷
- **四要件**：侵权行为 + 损害后果 + 因果关系 + 过错
- **归责原则四类**：过错责任（原则）/过错推定（8种情形：教育机构/医疗机构/建筑物搁置物/堆放物/公共道路/地下设施/动物园等）/无过错责任（7种情形：产品责任/环境污染/高度危险/饲养动物/机动车/用人单位/个人劳务）/公平责任
- **损害赔偿**：人身损害（第1179条）+ 财产损害（第1184条）+ 精神损害（第1183条）+ 惩罚性赔偿

#### 公司纠纷
- **决议效力**：不成立（未开会/未表决/出席不足/表决不足）/可撤销（60日除斥期间/最迟1年）/无效（内容违法）
- **股权转让**：内部自由转让 / 外部通知+优先购买权（30日）/ 未登记不影响合同效力仅不得对抗善意第三人
- **法人人格否认**：纵向否认（股东→公司）/横向否认（关联公司人格混同：人员/业务/财务三要素）/一人公司举证倒置

#### 婚姻家事继承
- **离婚**：法定准予离婚情形（重婚同居/家暴虐待遗弃/赌博吸毒屡教不改/分居满2年/宣告失踪/判决不准离婚后分居满1年）+ 财产分割（共同财产均等分割/个人财产归个人/房产区分/夫妻共同债务（第1064条））+ 子女抚养（<2岁随母/2-8岁最有利/≥8岁尊重意愿+抚养费20%-30%）
- **继承**：法定继承（两顺序+代位继承）/六种遗嘱形式（自书/代书/打印/录音录像/口头/公证）/遗赠扶养协议（优先于遗嘱和法定继承）/必留份（第1141条）

### 举证责任分配
- 一般原则：谁主张谁举证（《民事诉讼法》第67条第1款）
- 八种法定倒置情形（对应各过错推定/无过错责任条款）
- 证明标准：一般→高度盖然性 / 恶意串通欺诈胁迫→排除合理怀疑

### 抗辩体系
- **合同八大抗辩**：同时履行/先履行/不安/抵销/时效/免责条款（人身损害免责无效+故意重大过失免责无效）/情势变更（不可预见+非商业风险+明显不公平）/不可抗力（三不能标准+通知义务+因果关系）
- **侵权八项免责/减责事由**：受害人故意/与有过失/第三人原因/不可抗力/正当防卫/紧急避险/自甘风险/自助行为
- **通用反驳思路**：「合同有约定」不构成正当理由 / 「对方未提异议」≠放弃权利 / 「行业惯例」≠合法

### 请求权基础六层检查次序
```
契约上请求权 → 类似契约请求权（缔约过失/无权代理）→ 无因管理 → 物权请求权 → 不当得利 → 侵权行为
```

## 二、刑事（criminal）· `rules/52_criminal_domain.md`

### 法律依据
- 《刑法》（2020修正）为首要依据
- 《刑事诉讼法》（2018修正）为程序依据
- 《量刑指导意见》（法发〔2021〕21号）为量刑基准

### 定罪分析·三阶层审查框架

```
构成要件该当性（主体/行为/结果/因果/主观）
  → 违法性（是否存在阻却事由：正当防卫/紧急避险/法令行为）
  → 有责性（责任能力+违法性认识+期待可能性）
```

**四种常见罪名详解**：盗窃（第264条）/诈骗（第266条：五环因果链条缺一不可）/贪污（第382-383条：国家工作人员+利用职务便利+公共财物）/受贿（第385-386条：索贿不需"为他人谋取利益"即可构成）

**未完成形态**：预备（可比照既遂从轻/减轻/免除）/未遂（可比照既遂从轻/减轻）/中止（自动放弃且有效防止结果→没有损害免除/造成损害减轻）

**共犯体系**：主犯/从犯（应当从轻/减轻/免除）/胁从犯（按情节减轻/免除）/教唆犯（按共犯作用处罚，教唆未成年人→从重）

### 量刑分析·四步计算法
```
法定刑幅度 → 基准刑确定 → 调节基准刑 → 宣告刑（含缓刑判断）
```

**8种法定量刑情节**：

| 情节 | 法律依据 | 从宽/从重幅度 |
|---|---|---|
| 自首 | 第67条 | -20%~-40%（两个子要件：自动投案+如实供述） |
| 坦白 | 第67条第3款 | -20%以下 |
| 立功 | 第68条 | 一般-20%以下 / 重大-20%~-50%或免除 |
| 从犯 | 第27条 | -20%~-50%或免除 |
| 累犯 | 第65条 | +10%~+40%（前罪有期+5年内+再犯应判有期，未成年人除外） |
| 未成年人 | 第17条 | -10%~-50% |
| 犯罪未遂 | 第23条 | -20%~-40% |
| 犯罪中止 | 第24条 | 未造成损害→免除；造成损害→减轻 |

**认罪认罚阶段差异**：

| 阶段 | 从宽幅度 |
|---|---|
| 侦查阶段 | -30%（最高） |
| 审查起诉阶段 | -20% |
| 审判阶段（庭前） | -10% |
| 审判阶段（庭审中） | 酌情，通常≤5% |

### 证据规则

**非法证据排除体系**：
- 言词证据（6种排除情形）：刑讯逼供（绝对排除）/威胁（绝对排除）/引诱欺骗（程度审查）/非法限制人身自由（绝对排除）/未告知诉讼权利（相对排除）/疲劳审讯（单次超12小时→重点审查）
- 实物证据：不符合法定程序+严重影响公正+不能补正→排除
- 毒树之果：裁量排除（刑讯逼供情节严重+无法通过其他合法途径取得→可排除）

**补强证据规则**：口供补强（第55条：仅有供述不得定罪）/证人证言补强/辨认笔录补强

**口供审查三步法**：形式审查（时间/地点/人员/录音录像）→ 内容一致性（前后供述+与客观证据一致）→ 补强验证

**鉴定意见/电子数据/证人证言**：逐类逐维度审查要点

**质证方法论**：
- 质证五步法：识别质证对象 → 确定质证策略 → 撰写质证意见 → 推敲论证 → 发表质证意见
- 八类证据质证方法速查：物证/书证/证人证言/被害人陈述/被告人供述/鉴定意见/勘验检查辨认笔录/电子数据
- 四种质证方式：审查控方证据 / 提交辩方证据 / 申请控方证人出庭 / 申请辩方证人出庭

### 辩护策略组合（4组）

| 策略 | 适用条件 | 风险 |
|---|---|---|
| **无罪辩护（实体）** | 证据链严重缺失/存在确凿反证/构成要件不满足 | 无罪辩失败→丧失认罪认罚从宽→量刑可能更重 |
| **无罪辩护（程序）** | 存在严重程序违法+关键证据应予排除 | 须在庭前会议申请排非+提供具体线索 |
| **罪轻辩护** | 指控事实基本成立+证据较充分 | 主攻：重罪转轻罪+量刑情节最大化+认罪认罚越早越好 |
| **刑罚方式争取** | 罪名成立但刑期在3年以下 | 主攻：缓刑/免予刑事处罚/单处罚金 |

### 领域补充门禁（Gate 4 交付时强制启用）

#### 民商事 Y1-Y5
| 编号 | 门禁 | 内容 |
|---|---|---|
| Y1 | 诉讼时效 gate | 涉及请求权的已核查时效/除斥期间 |
| Y2 | 主体资格 gate | 当事人名称/统一社会信用代码/身份证号/住所地与工商登记或身份证明一致 |
| Y3 | 管辖依据 gate | 管辖法院的选择有明确法律依据（法定/协议/专属） |
| Y4 | 违约金计算 gate | 计算过程可验证，公式和数据均可回溯 |
| Y5 | 合同审核质量 gate | 已执行效力审查→主体授权审查→八维条款审查→修订方式路由 |

#### 刑事 Z1-Z6
| 编号 | 门禁 | 内容 |
|---|---|---|
| Z1 | 无罪推定 gate | 文书不存在有罪推定表述 |
| Z2 | 证据合法性 gate | 引用供述/证言标注取证程序状态 |
| Z3 | 量刑建议 gate | 量刑建议附计算过程和法律依据 |
| Z4 | 证据链闭合 gate | 定罪关键事实有≥2项独立证据相互印证 |
| Z5 | 辩护立场一致 gate | 定罪辩护和量刑辩护间不存在逻辑冲突 |
| Z6 | 当事人信息 gate | 当事人姓名/身份证号/住址与案卷一致 |
