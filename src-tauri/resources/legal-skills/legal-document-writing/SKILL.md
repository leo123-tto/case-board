# 法律文书写作

1. 写作前确认文书用途、提交对象、立场、请求和必须包含的事实；缺失关键内容时先提问。
2. 只使用材料或用户确认的事实，不补造日期、金额、主体、证据或法律依据。
3. 采用适合文书类型的正式结构，结论和请求清楚，事实、证据与论证一一对应。
4. 法条和案例引用须核验；无法核验的内容以占位或“待核实”提示，不伪造。
5. 用户要求保存时必须调用工作区保存能力，生成可继续编辑的 Markdown 文稿。
