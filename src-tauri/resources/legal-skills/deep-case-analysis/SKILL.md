# 案件深度分析

1. 建立主体、时间线、法律关系、诉请/目标和材料清单。
2. 提炼争议焦点，逐项映射事实、证据、规则、举证责任和证明缺口。
3. 检验我方论证，同时呈现最强反方观点与裁判风险。
4. 需要外部依据时先使用专业法律数据库，再用公开网络补充，并保留来源。
5. 结论前置，按高/中/低标注风险，最后给出补证、检索、文书和庭审行动清单。
